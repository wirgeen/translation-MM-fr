# D&D 5e – Traduction FR – Manuel des Monstres

Module FoundryVTT (v13+) de traduction française du compendium officiel **Monster Manual 2024** pour le système dnd5e.

## Dépendances

- Système : [dnd5e](https://foundryvtt.com/packages/dnd5e)
- Module requis : `dnd-monster-manual` (contenu officiel D&D)
- Module recommandé : [Babele](https://foundryvtt.com/packages/babele) (traduction automatique des compendiums)

## Installation

1. Copier le dossier `translation-MM-fr` dans `[FoundryVTT Data]/modules/`
2. Activer le module dans les paramètres du monde
3. Activer également Babele si ce n'est pas déjà fait

## Contenu traduit

| Compendium | Fichier |
|---|---|
| Acteurs (monstres) | `dnd-monster-manual.actors.json` |
| Contenu général | `dnd-monster-manual.content.json` |
| Aptitudes | `dnd-monster-manual.features.json` |
| Tables aléatoires | `dnd-monster-manual.tables.json` |
